## Animations

### Theme Toggle
```
Click 🌙 → Smooth fade → ☀️
All colors transition smoothly
Chart reloads with new theme
```

### AI Button
```
Continuous pulse:
  Scale: 1.0 → 1.05 → 1.0
  Glow: Subtle → Strong → Subtle
  Duration: 2 seconds
  Loop: Infinite
```

### Chat Modal
```
Open: Slide up from bottom (0.3s)
Close: Fade out (0.3s)
Messages: Slide in from bottom (0.3s)
```

### Typing Indicator
```
Three dots bounce in sequence:
  Dot 1: ↑ ↓
  Dot 2:   ↑ ↓  (0.2s delay)
  Dot 3:     ↑ ↓  (0.4s delay)
  Loop: Infinite while AI thinks
```

### Card Hover
```
Hover: Lift up 8px (0.3s)
Shadow: Increase intensity
Border: Glow effect
```

### Hero Background
```
Radial gradient rotates 360°
Duration: 20 seconds
Loop: Infinite
Creates living, breathing effect
```

## Color Transitions

### Light → Dark
```
Background: #ffffff → #1d1d1f
Text: #1d1d1f → #f5f5f7
Borders: #e5e5e7 → #3d3d3f
Cards: white → dark gray
Shadows: Subtle → Strong
Duration: 0.3s smooth
```

### Dark → Light
```
Reverse of above
Same smooth transition
Chart adapts colors
All elements update
```
