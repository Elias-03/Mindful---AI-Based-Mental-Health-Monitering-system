## Quick Start

1. **Run the server**:
   ```bash
   START.bat
   ```

2. **Open browser**: http://127.0.0.1:8000/

3. **Try these features**:
   - 🌙 Click theme toggle (top right) → Switch to dark mode
   - 🤖 Click AI button (bottom right) → Open chatbot
   - 💬 Type a message → Chat with AI
   - 🎨 Hover over cards → See lift effect
   - 📱 Resize window → See responsive design
